Its frontend lives in a separate repository.

## Your role
- Implement and maintain the backend for me.
- Use FastAPI, PostgreSQL, Redis, and Docker Compose.
- Keep the architecture small and suitable for a two-week personal project.
- I am learning frontend and infrastructure, not backend development.
- Use Swagger as API reperesenter and documentation.
- Explain API contracts, startup commands, and deployment implications.
- Keep backend theory brief unless I ask for it.
